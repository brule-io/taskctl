# Object-work specimen

This is independently authored test data for taskctl, not a snapshot or anonymized
copy of a consumer repository. Names, work and evidence are fictional.

`specimen.work/1` records use nested object fields and embedded lifecycle. Identity
is the complete `WORK-N` token, including leading zeroes. Labels are optional
annotations. Prerequisites are task references; feature association is a separate
index. This specimen has no roadmap concept. Closure narratives and checked flags
are historical facts, not native taskctl receipts.

The bounded conformance adapter accepts open/closed records only. Claimed or blocked
records, active ownership and required eligibility cannot be converted to optional
annotations: until a preserving mapping exists they must be rejected explicitly.
The schema label does not select an adapter or establish structural compatibility.
